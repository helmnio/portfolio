1 · What it needed

What the site had to do.

People planning a luxury trip browse for ideas before they get in touch. The site needed an inspiring way to explore itineraries, with enough filtering to be useful, repeated content that is easy to keep consistent, and a clear route to an enquiry.

2 · What a visitor can do

The site in use.

  • Open the itinerary archive and see a few featured itineraries at the top, then the full list as cards showing nights, title and a from-price.
  • Narrow the list by destination, trip type and price, and clear all filters in one click, with paging below.
  • Open an itinerary or an article, then enquire or call from the header.
  • Search the whole site from a dedicated search page.

3 · What I built

What I built, and how.

Itinerary inspiration

The archive lets visitors filter itineraries by category, tag and price with FacetWP, with a clear-filters control. Each card shows the number of nights and the from-price from ACF fields. Dropdown filters do not show result counts, which kept the design clean.

Random order that holds still

Showing itineraries in a random order stops the same few leading every visit, but plain random order breaks paging, because each page request reshuffles. A query filter swaps the database’s random order for a seeded one that changes every three hours, applied to the archive and to the queries FacetWP runs. An option in the admin switches random order on or off. When the seed rolls over the order changes, so someone browsing at that moment could see the list reshuffle.

Featured items that do not appear twice

Featured itineraries and featured journal articles are chosen in a block. The theme reads that choice and excludes those items from the list underneath, so a featured item is never shown a second time further down.

Content written once

Content that repeats across pages, such as the inspiration hero, featured itineraries, reviews and the call to action, is stored once on a single “global blocks” page. A shortcode takes the block’s name and renders it with all its fields. Updating the content there updates every page that uses it.

A second face for the same theme

The theme also contains a separate header and page template for a management section, with its own logo, phone and enquiry options. A page background choice in ACF lets editors set the page tone. Block types include mosaics, scrolling content, logo strips, reviews and image-link panels.

Publication dates with a safe rollout

New rules decided which pages show a date: only normal journal posts, and only when “Show date” is ticked. I wrapped the rule in a switch that first applied it to logged-in users only, so it could be checked before it applied to everyone.

4 · Decisions

Choices worth explaining.

Keep a random order stable

Problem

A random listing breaks pagination, because each page request reshuffles the results.

Approach

A query filter seeds the random order so it stays the same for three hours, including in queries run by FacetWP.

Trade-off

When the seed rolls over, the order changes mid-session.

Store repeated sections once

Problem

The same hero and featured sections appear on several pages, and copying them means updating each one.

Approach

Global blocks are fetched by name through a shortcode.

Trade-off

A change to a global block affects every page that uses it.
